# Sociedade dos Ventos — fontes suspensas

Vila, monge e bisão foram removidos do build ativo por decisão do autor em
16/11/2026, para concentrar o mod no vento e no planador. Esta pasta preserva
fontes, testes, modelos e recursos originais para possível reutilização.

Não é um source set Gradle e não entra no JAR. Restaurar exige reintroduzir
registros, dependências e recursos, além de executar a validação novamente.
Os geradores arquivados usam caminhos relativos da antiga árvore e precisam
ser adaptados antes de executar. Não os execute nesta pasta para restaurar o mod.
